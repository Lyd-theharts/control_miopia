ESPECIFICACIONES TÉCNICAS:
--------------------------
- Backend: Java 17 (Spring Boot 3.5.1)
- Frontend: Angular 20
- Base de Datos: MySQL 8.0
- Servidor Web: Nginx (para el frontend)

REQUISITOS:
-----------
- Docker Desktop instalado y en ejecución.

INSTRUCCIONES DE EJECUCIÓN RÁPIDA (RECOMENDADO):
------------------------------------------------
Para facilitar la corrección, el proyecto ha sido subido a Docker Hub. 
No es necesario compilar el código manualmente.

1. Sitúese en la raíz de esta carpeta (donde está el archivo docker-compose.yml).
2. Ejecute en su terminal:
   
   docker-compose up -d

3. Acceda a la aplicación en: http://localhost:4200

UBICACIÓN DEL CÓDIGO FUENTE:
----------------------------
El código fuente completo y los Dockerfiles originales se encuentran en 
la carpeta /FUENTES de este paquete y en el repositorio:
https://github.com/Lyd-theharts/control_miopia.git
